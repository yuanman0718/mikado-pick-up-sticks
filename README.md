# MIKADO

A browser-based single-player Mikado pick-up-sticks game with a minimal Bauhaus-inspired interface.

## Play

Open `index.html` in a browser. The game is fully self-contained and does not require a build step or external dependencies.

## Controls

- Drag empty space to rotate the view.
- Scroll or pinch with two fingers to zoom.
- Drag a stick along its length to pull it from the pile.
- On touch devices, use one finger to rotate and two fingers to zoom.

## Audio

Sound effects and the ambient music loop are generated with the Web Audio API. Audio starts after the first user interaction, as required by browser autoplay policies.
